Contexto

Vas a trabajar durante todo el curso sobre un caso de negocio de una empresa distribuidora de tecnología llamada RetailPro.
Tienen datos de ventas, clientes y productos pero nadie los ha analizado sistemáticamente.
Tu trabajo a lo largo del curso es construir el sistema de análisis completo, desde la base de datos hasta el dashboard ejecutivo.
Todo lo que entregues en cada módulo se suma al proyecto final.
